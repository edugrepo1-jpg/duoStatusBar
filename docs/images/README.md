# Capturas e demonstração

97 PNGs de páginas reais do aplicativo renderizadas em Android 15/API 35 simulado. Estados de prévia são simulados.

Os cinco arquivos `demo-*.png` e o GIF `demo-animacoes.gif` usam o renderizador Canvas de produção dentro de uma moldura de telefone e telas do sistema ilustrativas. Não são fotografias ou gravação de Samsung nem evidência de integração na One UI. Nenhum dado pessoal foi usado.
