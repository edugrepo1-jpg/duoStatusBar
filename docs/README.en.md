- Preview and adjust animations, unlock effects and transitions.
- Find everything in Home, Visual, Effects and Settings.

## Installation

**Android 13+ · root required · Portuguese, English and Spanish**

1. Install the APK and choose your language.
2. In LSPosed, enable DUO Recreate for System UI and reboot. To try without LSPosed, open Settings → Advanced → Root without LSPosed and authorize it in your root manager.
3. Enable the bar at the top of Home. Customize in Visual and try effects in the preview.

LSPosed mode available; standalone root mode is experimental. Icon hiding and panel support vary by ROM.
