# Instalação · DUO Recreate

[Português](../README.md) · [English](README.en.md) · [Español](README.es.md)

**Android 13+ · root necessário · português, inglês e espanhol**

1. Instale o APK e escolha o idioma. [Baixar APK](https://github.com/edugrepo1-jpg/duoStatusBar/releases/latest).
2. No LSPosed, ative DUO Recreate para System UI e reinicie o aparelho. Para testar sem LSPosed, use Ajustes → Avançado → Root sem LSPosed e autorize no gerenciador root.
3. Ative a barra no topo de Início. Personalize em Visual e experimente os efeitos na prévia.

Ao atualizar, instale por cima e reinicie o processo DUO ou o aparelho. Não use dois módulos Duo ao mesmo tempo.

Modo LSPosed disponível; modo root independente experimental. A ocultação dos ícones e o suporte aos painéis variam conforme a ROM.

Package: `io.github.RECREATE.statusbar`.
